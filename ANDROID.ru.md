# CSQTT Compatible для Android

Версия приложения: **2.5.0.4**. Android **8.0 и новее**, телефоны и планшеты.
Приложение содержит оптимизированное Rust-ядро и совместимость с серверами
CSQTT 2.1.9 и 2.5.0. Основано на Android-приложении CSQTT автора amurcanov.

## Установка

1. Скачайте [универсальный APK](https://github.com/mikhail384/tunnelscope/releases/download/csqtt-android-v2.5.0.4/CSQTT-Compatible-2.5.0.4-universal.apk).
2. Откройте файл и разрешите браузеру установку приложений, если Android попросит.
3. Откройте **CSQTT Compatible**, добавьте ссылку подключения или отсканируйте
   QR-код из панели CSQTT. Нужна ссылка клиента, а не адрес входа в панель.
4. Отключите другое VPN-приложение, нажмите подключение и подтвердите системный
   запрос Android на создание VPN.

Все варианты APK находятся на [странице выпуска](https://github.com/mikhail384/tunnelscope/releases/tag/csqtt-android-v2.5.0.4).
Если не знаете процессор устройства, выбирайте `universal`. Также доступны
`arm64-v8a`, `armeabi-v7a` и `x86_64`.

Идентификатор пакета — `com.csqtt.compatible`. Приложение устанавливается рядом
с оригинальным CSQTT: его профиль нужно импортировать заново. Установка APK
не изменяет сервер или его панель. Одновременно Android использует один VPN.

Для сервера 2.1.9 оставьте режим SRTP **auto**. При первом подключении переход
на старый протокол может занять около 10 секунд. Из-за отдельной подписи приложения
Android выдаёт другой `ANDROID_ID`: если старый сервер сообщает `device_mismatch`,
снимите привязку устройства у этого клиента в панели либо создайте отдельного клиента.

## Сборка из исходников

Используйте ветку `csqtt-compatible`. Нужны полный JDK 21, Android SDK 37,
NDK r28c, Rust 1.97.1, `cargo-ndk`, `cargo-zigbuild`, Zig 0.14, CMake, Ninja
и PowerShell 7 (`pwsh`). SDK и NDK задаются через `ANDROID_HOME` и
`ANDROID_NDK_HOME`; инструменты должны быть доступны через `PATH`.

Задайте `KEYSTORE_FILE`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`
для собственной release-подписи через переменные окружения или локальный
неотслеживаемый `local.properties`. Не публикуйте ключ и пароли.

```bash
cargo install cargo-ndk --locked
cargo install cargo-zigbuild --locked
rustup target add x86_64-unknown-linux-musl aarch64-unknown-linux-musl armv7-unknown-linux-musleabihf
bash scripts/build_android.sh
```

Сценарий собирает Android-ядро для трёх архитектур с выравниванием 16 КиБ,
три серверных бинарника для встроенного развёртывания, проверяет их provenance,
запускает JVM-тесты и создаёт подписанные APK в `app/release/`.
Проверки provenance и release-подписи обязательны.

`--native-only` пересобирает только Android-ядро. `--package-only` использует
готовые бинарники, предварительно проверяя соответствие исходникам.
`CSQTT_BUILD_JOBS` ограничивает параллелизм Rust-сборки (по умолчанию 3).
При ограниченной памяти задайте `org.gradle.jvmargs=-Xmx3g` в пользовательском
`~/.gradle/gradle.properties`.

Для обновления уже установленного APK нужен **тот же ключ подписи**.
Ключ этого выпуска сохранён отдельно от репозитория и не включён в релиз.
Проверка обновлений принимает только опубликованные стабильные выпуски
с тегами `csqtt-android-v…` этого репозитория.

## Границы проверки

Для выпуска проверены:

- **208 JVM-тестов** — без ошибок; Android Lint и обязательная release-проверка пройдены.
- Подписи всех четырёх APK, имя пакета, версия, минимальный Android API и ZIP-выравнивание.
- Совпадение Android-ядер и трёх встроенных серверов с манифестами SHA-256.
- ELF-архитектуры и выравнивание 16 КиБ у всех трёх Android-ядер;
  запуск нативного процесса x86_64 внутри Android.
- Установка и открытие универсального APK в эмуляторе Android 15 (x86_64)
  с экраном 800×1280.

SHA-256 сертификата подписи:

```text
952a5e7ebb9decd7a315821c6a0f7ac71a4382d565b52c5ceefb8b3f97a982fe
```

Контрольные суммы APK и машинный отчёт проверки приложены к выпуску как
`SHA256SUMS` и `verification.json`.

Тесты протокола и локальный TURN-сценарий описаны в [COMPATIBILITY.ru.md](COMPATIBILITY.ru.md).
Работа через внешний VK TURN и на физических устройствах требует проверки
с действующим профилем пользователя. Результаты CPU-замеров в
[PROTOCOL.ru.md](PROTOCOL.ru.md) не означают такое же увеличение скорости Интернета.
