Как читать эти данные

Трафик клиента

Прирост штатных счётчиков VPN. Первый замер — исходная точка, старый трафик не добавляется в историю. Сброс счётчика обрабатывается отдельно.

Домены и посещения

Домен означает сетевое обращение. Оно может быть фоновым. TLS SNI и HTTP дают имя напрямую; сопоставление с DNS отмечается как предположение.

Владелец IP

ASN и организация из RIPEstat показывают оператора сети или хостинг. Это не доказывает, какому сайту или приложению принадлежит соединение. Запросы содержат только IP назначения.

Ограничения охвата

Исходящие потоки прокси без надёжной привязки отмечены отдельно. Данные Xray по доменам не содержат байтов отдельных соединений. QUIC/ECH, потери захвата и отдельные сетевые пространства Docker ограничивают видимость. История хранится 14 дней, максимум 100 000 потоков.

Ограничение скорости

0 — без ограничения в этом направлении. Общий лимит задаётся каждому клиенту отдельно; персональные значения заменяют общий.

Для Xray лимит включается на новых соединениях — переподключите VPN на устройстве. Реальная скорость может быть ниже заданного порога; допускаются короткие всплески.
