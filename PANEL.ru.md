# Панель CSQTT: выбор 2.1.9 / 2.5.0

Обновление панели приходит с серверной сборкой `2.5.0-compatible.2`.
Повторно выполните на сервере прежнюю команду:

```bash
curl -fsSL https://raw.githubusercontent.com/mikhail384/tunnelscope/csqtt-compatible/install.sh | bash
```

Установщик сохраняет базу, действующие доступы, порты, логин и пароль панели.
Сначала он собирает обновление, затем перезапускает службу с проверкой работы
и автоматическим откатом при неудаче. Открытую страницу панели после обновления
нужно перезагрузить в браузере.

При сборке обновляются даты извлечённых исходников: кэш Cargo сохраняет зависимости,
а изменённые сервер и встроенная панель пересобираются даже из архива с фиксированными датами.

## Подключение телефона, планшета или компьютера

1. Откройте полный адрес панели, который вывел установщик, и войдите.
2. В блоке «Быстрое подключение» выберите устройство и версию приложения.
3. Создайте доступ либо найдите существующий на вкладке «Доступы».
4. Нажмите «Подключить устройство». В окне можно снова изменить устройство
   или версию; QR-код, ссылка и кнопка открытия обновятся одновременно.
5. Нажмите «Открыть …» на этом устройстве либо отсканируйте QR-код с другого.
   После импорта включите подключение в приложении.

| Выбор | Приложение и ссылка |
| --- | --- |
| Android + 2.5.0 | CSQTT 2.5.0, зашифрованная ссылка `csqtt://…` |
| Android + 2.1.9 | CSQTT 2.1.9, ссылка `csqtt://connect?…` |
| Windows / Linux | focsq, совместимый формат 2.1.9 |
| iPhone / iPad | VK TURN Proxy, импорт `vkturnproxy://import?data=…` |

Для Windows и Apple выбран режим 2.1.9: эти приложения используют соответствующий
совместимый формат. Переключатель 2.5.0 для них недоступен. Для macOS в этой сборке
не добавлялся отдельный клиент.

Выбор запоминается в этом браузере. Кнопка «Скопировать ссылку подписки» добавляет
выбранные устройство и версию в адрес страницы. Получатель откроет её с тем же
выбором и сможет изменить его самостоятельно. На групповых страницах и в панели
администратора группы действует такой же переключатель.

Если для старого приложения не настроены VK-хеши, страница показывает подсказку.
Добавьте ссылки VK-звонков в настройки доступа. VK access token приложения 2.5.0
не заменяет эти ссылки для старых клиентов.

## Что переключает версия

Переключатель выбирает формат подключения для приложения. Серверная программа
остаётся совместимой сборкой на базе 2.5.0 и одновременно обслуживает клиентов
2.1.9 и 2.5.0. Выбор в панели не переустанавливает сервер, не меняет пароль,
не отключает уже подключённые устройства и не ограничивает доступ одной версией.
Установка оригинального серверного бинарника 2.1.9 из панели не реализована.
Возврат сохранённой установки 2.1.9 из терминала доступен через команду
`--rollback 2.1.9`: [локальная копия и восстановление](BACKUP.ru.md).

## Если потерян пароль панели

В терминале сервера:

```bash
sudo grep -E '^CSQTT_WEB_(USER|PASS)=' /etc/csqtt/compatible.env
```

## Проверка изменений

Серверные тесты проверяют совместимость форматов, сохранение пароля и всех VK-ссылок,
поля JSON подписок, подсказку при отсутствии хешей и экранирование имени клиента.
Браузерная проверка использует реальные HTML/JS панели и локальные ответы API:

```bash
python3 tests/panel_browser.py
```

Для неё нужны Python-пакет `playwright` и Chromium. Проверяются оба формата,
копирование и открытие, обновление QR, сохранение выбора, ссылки подписок,
групповые страницы, размеры планшета и телефона, повреждённое и недоступное
хранилище браузера. Запуск физических Android/Windows/iOS-приложений эта
проверка не заменяет.

HTML-шаблоны, стили и переключатель находятся в `rust-server/web/` и встраиваются
в сервер при сборке. Они включены в автономный установщик и контроль происхождения
серверных assets. При изменениях пересоберите установщик согласно `INSTALL.ru.md`.
