SOCKS5 UDP

  • Зачем нужно? Маршрутизировать трафик из CSQTT в Xray, 3x-ui и другие панели. Это нужно, чтобы маршрутизировать трафик через geoip/geodat и работать с любыми возможностями ваших панелей.
  • Как работает? CSQTT передаёт TCP и UDP в локальный SOCKS5. Если прокси недоступен, используется прямой выход через основной VPS.
  • Как настроить? В соответствующем ядре или веб-панели заранее создайте инбаунд SOCKS5-прокси (в некоторых панелях он может называться mixed) с предпочитаемым портом и включите UDP в настройках прокси. Затем укажите в панели CSQTT тот же самый порт.

VK хеши в ссылке

Укажите от 1 до 6 VK-хешей через запятую без пробелов. Вставляйте только сами значения хешей. Они будут добавлены в ссылку CSQTT v2, и пользователю не придётся вводить их вручную.

Настройка VK токенов

Если сохранить VK токен здесь, все CSQTT-ссылки с включённой функцией VK токена будут автоматически использовать этот общий токен.

Документация REST API

Интеграция с Telegram-ботами, панелями управления и биллингом

Базовый адрес API (Base URL)
Авторизация запросов (Headers)
X-API-Key: <пароль_панели> Рекомендуемый
Authorization: Bearer <пароль> Стандарт Bearer
POST /api/clients Создание нового клиента (ключа)

Создает ключ доступа. Если password не указан, сервер сгенерирует надежный криптостойкий пароль. В ответе возвращаются готовая ссылка link (csqtt://...) и срок expires.

Тело запроса (JSON):
{
  "name": "Пользователь @username",
  "days": 30,                     // 0 = бессрочно, 1..3650 = дней
  "password": "custom_pass",       // опционально (мин. 4 символа)
  "peer_port": 46000,             // опционально (UDP порт)
  "group_id": "group_id_here",     // опционально (привязка к группе)
  "vk_token": false,               // опционально (общий VK токен)
  "hash": "hash1,hash2"            // опционально (VK хеши)
}
Пример curl:
curl -X POST https://example.com/api/clients \
  -H "X-API-Key: YOUR_PASSWORD" \
  -H "Content-Type: application/json" \
  -d '{"name":"TelegramUser","days":30}'
GET /api/clients Список всех клиентов (с фильтрацией)

Возвращает массив клиентов: расход трафика, статус активности, срок, ip, sub_uuid и link.

Фильтры (Query): ?group_id={id|root}, ?active=true|false, ?search=текст.

GET /api/clients/{password} Информация по одному клиенту

Возвращает объект клиента по его паролю (трафик, активные сессии, IP-адреса, скорость, срок, ссылка подписки и link).

POST /api/clients/{password} Обновление параметров клиента

Изменение имени, срока, пароля, UDP-порта, группы или VK параметров: 

{ "name": "Новое Имя", "days": 60, "peer_port": 46000, "group_id": "" }
POST /api/clients/{password}/extend Продление срока действия ключа

Продлевает ключ на указанное число дней. Если ключ истёк — отсчет от текущего момента; если активен — дни прибавляются к дате окончания: 

{ "days": 30 }
Ответ: { "ok": true, "expires": 1791600000 }
POST /api/clients/{password}/toggle Блокировка / разблокировка

Переключает статус клиента. При деактивации активные туннели ключа мгновенно сбрасываются. Ответ: { "ok": true, "active": false }.

POST /api/clients/{password}/unbind Сброс привязки клиента

Сбрасывает эпоху пароля и активные сессии клиента, позволяя подключиться заново.

POST /api/clients/{password}/reset-traffic Сброс расхода трафика в 0

Сбрасывает счетчики отправленного и принятого трафика в базе данных и у активных сессий в ноль.

POST /api/clients/{password}/sub-link/regenerate Перегенерация ссылки подписки

Генерирует новый постоянный sub_uuid для клиента или Главного пароля, мгновенно аннулируя старый адрес подписки. 

Ответ: { "ok": true, "sub_uuid": "e2a3b4c5-..." }
PUT /api/clients/{password}/vk Персональная настройка VK токена и хешей 
{ "vk_token": true, "vk_hashes": "hash1,hash2" }
DELETE /api/clients/{password} Удаление клиента

Полностью удаляет ключ с сервера и немедленно разрывает активные соединения.

GET /api/links Массив всех готовых ссылок csqtt://

Возвращает компактный массив объектов всех клиентов и мастер-пароля с готовыми ссылками csqtt://... и sub_link для ботов.

POST /api/links/batch-vk Пакетная настройка VK токенов и хешей 
{ "vk_token": "vk1.a...", "vk_hashes": "hash1,hash2", "apply_to_all_clients": true }
POST /api/clients/batch-toggle Массовое переключение активности 
{ "passwords": ["p1", "p2"], "active": true }
POST /api/clients/batch-extend Массовое продление срока ключей 
{ "passwords": ["p1", "p2"], "days": 30 }
POST /api/clients/batch-reset-traffic Массовый сброс расхода трафика 
{ "passwords": ["p1", "p2"] }
POST /api/clients/batch-delete Массовое удаление клиентов 
{ "passwords": ["p1", "p2"] }
POST /api/clients/batch-group Массовое перемещение между группами 
{ "passwords": ["p1", "p2"], "group_id": "target_group_id_or_empty" }
GET /api/groups Список групп и лимитов скорости

Возвращает все группы: id, name, ограничение скорости rate_limit_mbps, привязанное правило routing_rule_id, постоянный sub_uuid групповой подписки, статус админ-панели и admin_uuid.

POST /api/groups Создание группы 
{ "name": "VIP Клиенты", "rate_limit_mbps": 100, "routing_rule_id": "" }
PUT /api/groups/{id} Редактирование группы 
{ "name": "Новое Имя Группы", "routing_rule_id": "rule_id_here" }
DELETE /api/groups/{id} Каскадное удаление группы

Внимание: удаляет группу и безвозвратно удаляет всех входящих в неё клиентов.

POST DELETE /api/groups/{id}/admin-link Управление админ-панелью группы

POST генерирует секретную ссылку /{admin_uuid}/admin для делегированного управления клиентами группы без доступа к настройкам сервера. DELETE отключает ссылку.

POST /api/groups/{id}/admin-link/regenerate Перегенерация секрета админ-панели

Выпускает новый admin_uuid группы. Предыдущая ссылка мгновенно аннулируется.

POST /api/groups/{id}/sub-link/regenerate Перегенерация ссылки групповой подписки

Выпускает новый уникальный sub_uuid для групповой подписки /{group_sub_uuid}/sub-group. Ответ: { "ok": true, "sub_uuid": "..." }.

GET /api/groups/{id}/clients Список клиентов выбранной группы

Возвращает JSON-массив всех клиентов, входящих в группу с указанным id.

Изоляция доступа: эндпоинты подписок и управления группами открываются напрямую от корня со своим персональным секретным UUID (без префикса главной админки). Это предотвращает утечку пути главной панели администратора.
GET /{sub_uuid}/sub Веб-страница персональной подписки (HTML)

Публичная веб-страница подписки клиента или Главного пароля (без необходимости авторизации). Содержит живой векторный QR-код, прямую ссылку csqtt://connect?..., кнопку «Подключить в приложении CSQTT» (с нативным уведомлением в приложении), контрастную кнопку копирования и инструкции.

GET /{sub_uuid}/json Конфигурация подписки клиента (JSON)

Чистый эндпоинт для автоматического обновления конфигурации клиентом или ботом (также доступны алиасы /{sub_uuid}/sub.json и /api/sub/{sub_uuid}): 

{
  "v": 2,
  "name": "Пользователь",
  "host": "vpn.example.com",
  "peer": 46000,
  "password": "p_abc123...",
  "vk_token": "...",
  "hash": "...",
  "link": "csqtt://connect?v=2&host=vpn.example.com&peer=46000&password=..."
}
GET /{group_sub_uuid}/sub-group Групповая страница подписок (HTML)

Публичная адаптивная страница для группы. Выводит всех активных клиентов группы в виде аккуратной сетки с QR-кодами, ссылками, кнопками копирования и быстрого подключения в CSQTT.

GET /{group_sub_uuid}/json Конфигурации клиентов группы (JSON)

Возвращает JSON-массив с параметрами подключения всех активных клиентов группы (также доступны алиасы /{group_sub_uuid}/sub-group.json и /api/sub-group/{group_sub_uuid}): [{ "name": "...", "link": "csqtt://...", ... }].

GET /{admin_uuid}/admin Панель управления группы (HTML & API)

Автономная панель для модератора группы. Управление клиентами и настройками группы изолировано под префиксом /{admin_uuid}/api/... (получение данных группы: GET /{admin_uuid}/api/data, создание клиента: POST /{admin_uuid}/api/clients).

GET POST /api/routing-rules Правила выборочной маршрутизации

GET возвращает список настроенных правил обхода. POST создает новое правило с доменами, IP-диапазонами и outbound-действием (прямой выход или прокси): 

{
  "name": "YouTube & Discord",
  "domains": ["youtube.com", "googlevideo.com", "discord.com"],
  "ip_ranges": ["162.158.0.0/15"],
  "action": "proxy", // "direct" или "proxy"
  "proxy_id": "proxy_uuid_here"
}
PUT DELETE /api/routing-rules/{id} Редактирование и удаление правила

PUT обновляет список доменов и IP правила, DELETE удаляет правило.

GET /api/template-domains Шаблоны доменов популярных сервисов

Возвращает готовые списки доменов для YouTube, Discord, Instagram, Twitter/X, ChatGPT, Spotify и др.

GET POST /api/local-proxy Outbound прокси (SOCKS5 / HTTP)

Добавление внешних upstream прокси-серверов для маршрутизации трафика: 

{
  "name": "Германия SOCKS5",
  "protocol": "socks5", // "socks5" или "http"
  "host": "198.51.100.1",
  "port": 1080,
  "username": "user",
  "password": "pass"
}
PUT DELETE /api/local-proxy/profiles/{id} Управление профилем прокси

Редактирование хоста/порта/пароля или удаление профиля прокси.

POST /api/local-proxy/activate/{id} Активация системного прокси

Назначает выбранный прокси глобальным шлюзом по умолчанию (или POST /api/local-proxy/deactivate для отключения).

GET /api/stats Мониторинг нагрузки и ресурсов

Возвращает нагрузку CPU (%), использование RAM (байт), число активных туннелей и скорость сети.

GET /api/diagnostics/dpi DPI диагностика и телеметрия пакетов

Возвращает статус кольцевого буфера DPI, количество зафиксированных аномальных пакетов и последние семплы фреймов для отладки цензуры.

POST /api/memory/trim Принудительное освобождение RAM (Trim)

Вызывает сброс неиспользуемой памяти в ядро операционной системы для минимизации RSS.

GET POST /api/settings Глобальные настройки сервера

Получение и сохранение настроек: DNS, MTU, stealth-домены маскировки, интервал автоперезапуска, лимиты.

POST /api/settings/dns Быстрая смена DNS 
{ "dns_provider": "cloudflare", "dns_primary": "1.1.1.1", "dns_secondary": "1.0.0.1" }
POST /api/settings/restart-interval Интервал автоперезапуска (в часах) 
{ "interval_hours": 12 }
POST /api/settings/master-password Смена главного пароля сервера 
{ "password": "новый_пароль" }
GET POST /api/export и /api/import Резервная копия и неразрушающее слияние

GET /api/export выгружает полный JSON базы. POST /api/import производит умное слияние: клиенты и настройки добавляются к существующим без перезаписи и потери трафика.

GET POST /api/logs Журнал логов сервера

GET /api/logs возвращает строки логов. POST /api/logs/toggle включает/выключает запись, POST /api/logs/clear очищает буфер, а GET /api/logs/download отдает текстовый файл.

POST /api/reboot Перезапуск сервера CSQTT

Инициирует контролируемый мягкий перезапуск процесса CSQTT на сервере.
